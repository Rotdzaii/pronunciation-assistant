# Archived Legacy Code

These folders contain archived legacy and prototype code. They are kept as reference material only and are not part of current local development.

Current active projects:

- `fastapi-backend/` is the active FastAPI backend.
- `frontend/` is the active Expo frontend.
- `run_server.bat` is the current launcher from the repository root.

Do not use these archived paths for current development:

- Do not run root npm scripts from the archived NestJS backend.
- Do not run `uvicorn api.main`.
- Do not install or use the old root `requirements.txt`.

The AI prototype code may be referenced later when building a dedicated `ai-worker/`.
