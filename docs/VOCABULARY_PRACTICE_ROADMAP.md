# Vocabulary Practice Roadmap

## Phase V1: Data Design And Seed List

- define pronunciation-focused vocabulary entities
- prepare a static seed vocabulary list
- define pronunciation metadata fields such as phonetic form, target phonemes, and common mistake tags

## Phase V2: Frontend Practice From Vocabulary Item

- allow students to open a vocabulary item and start pronunciation practice
- connect a vocabulary item to the existing pronunciation practice flow
- show pronunciation-focused feedback after each attempt

## Phase V3: Teacher Assignment

- allow teachers to create or select vocabulary sets
- assign sets to students or classes
- view basic assignment completion and pronunciation practice activity

## Phase V4: Adaptive Review And Gamification

- prioritize review words based on weak phonemes
- add lightweight progress and challenge mechanics
- support repeated review for commonly mispronounced words
